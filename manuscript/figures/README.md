## 화살표 여백 — 2026-10-26

옆으로 들어가는 화살표가 있는 9개 도표는 본문 박스를 x=70·폭500으로 배치한다. 640폭 캔버스에서 좌우 70의 공간을 확보하고, 입력 화살표 끝은 박스에서 6만큼 떨어뜨린다. 글자 크기와 판단 경로는 유지한다. 화살표가 없는 집합 그림은 기존 폭을 유지한다.

화살촉은 `markerUnits="userSpaceOnUse"`로 지정해 선 두께에 비례해 커지지 않게 한다. 촉의 끝을 refX와 일치시키고, 캔버스 폭640/760/960에서 각각14/17/21로 지정한다. 선의 마지막 구간에는 화살촉과 별도로 보이는 길이를 남긴다. 합류에서는 여러 화살촉을 겹치지 않고 합류점과 한 개의 다음 화살표를 사용한다. 수정 뒤 실제 렌더링에서 박스 가림·글자 넘침·모바일 선 가독성을 함께 확인한다.

2026-10-15 후속 기준으로 하네스 사이클의 정책·집행·하단 설명에 자동 처리/사람 판단/보류와 개별 승인 없는 수용·배포를 반영했다. 원칙의 타협·우회 금지와 전체 네 단계는 유지한다.

2026-10-21: 하네스 사이클의 중심을 의도로 변경했다. 의도는 목적·기대 결과·성공 기준을 통해 맥락 해석과 수행의 방향을 제공한다. 네 단계·상위 원칙·정책이 허용한 자동 실행은 유지하며, 에이전트는 그 안의 수행 주체로 설명한다. 본문 캡션·대체 텍스트·SVG title/desc를 맞췄다.
