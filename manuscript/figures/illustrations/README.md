2026-10-21 저자 요청으로 제작. 스타일 A: 코발트·아이보리의 편집 삽화.

- ch04-two-improvement-loops: 의도 개선과 하네스 개선, 해당 절 끝 배치.
- ch09-shared-responsibility: 제품·정책·하네스 운영 책임, 역할 설명 끝 배치.

PNG는 imagegen으로 생성한 1536×1024 원본이다. WebP는 같은 픽셀 크기에서 cwebp 품질86으로 압축한 웹용 파일이며 시각적 장면을 변경하지 않았다. 생성 도구의 정확한 모델 식별자는 확인하지 않았다. 인물과 장면은 실제 고객·조직·사건의 재현이 아닌 개념 설명이다.

로보코 원본 SVG는 기존 website/public/images/roboco-logo.svg에서 동일하게 복사했다. 저자가 2026-10-21 설명한 의미는 ‘로봇 고양이를 단순화한 로고이며 초기 바이브 코딩의 터미널 환경 AI를 형상화’한 것이다. 생성 모델로 로고를 다시 그리지 않고, 본문에서 별도 원본 레이어로 에이전트 활동 영역에 표시한다. 역할별 인물 수는 필수 조직 구성이나 직책 수가 아니다.

로고의 기존 권리·상표 고지는 유지한다(website/public/images/NOTICE.txt). 삽화와 로고의 권리는 구분한다. 생성 삽화는 책 콘텐츠의 라이선스 안내 범위에 포함하며 로고의 권리를 CC BY-SA로 변경하지 않는다.

빌드 도구가 WebP를 website/public/illustrations/로 복사한다. 원본 PNG는 웹 배포에 포함하지 않는다. 캡션과 대체 텍스트는 각 장 원고에서 관리한다. 그림만으로 세부 조건을 확정하지 않으며 본문과 기존 정책 도표를 함께 읽는다.
