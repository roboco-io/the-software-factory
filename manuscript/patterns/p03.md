# P03 실행 가능한 계약

상태: 초고 · 저자 검토 대기 · 실제 업무 효과 미검증

## 상황과 반복되는 문제

작업을 다른 사람이나 에이전트에게 맡기고 결과를 수용할 조건이 필요한 상황에 적용을 검토한다. 말로 합의한 내용을 실행 단계에서 검증할 수 없다.

## 상충하는 요구

사전에 충분히 조건을 연결할 필요와 정형화·탐색 제한의 비용이 충돌한다.

## 해결 원리와 적용

입력과 출력과 권한과 완료 증거 및 실패 처리를 실행 계약에 명시한다. 이 원리는 이 책의 설계 제안이며 효과가 입증된 보편 법칙이 아니다.

입력·출력·권한·증거·실패 처리의 책임을 연결한다. 가정과 미결 판단을 나누고 시작·제한 시작·보류의 조건을 정한다. 변경 시 진행 중 작업의 적용 범위를 재확인한다.

계약에는 개별 승인 없이 수행·수용·반영·배포할 조건, 자동 처리할 예외·복구, 사람에게 넘길 판단과 조건 미확인의 보류를 담는다. 같은 계약을 적용하는 자동 허용 판정도 가능하며 사람의 시작 승인을 모든 작업의 기본 단계로 두지 않는다.

## 결과와 비용

정형화에 비용이 들며 새로운 문제의 탐색을 과도하게 제한할 수 있다. 입력을 준비하고 계약을 바꿀 때 진행 중 작업의 적용 범위를 다시 확인해야 한다. 반복 위임에서 누락 질문과 수용 분쟁을 줄일 필요가 있을 때 이 준비 부담을 감수한다.

## 실패 경계와 적용하지 않을 조건

형식의 빈칸을 채워도 실제 권한과 검증이 맞지 않을 수 있다. 탐색은 배울 결과를 계약으로 정하며 완성품 기준을 일률 적용하지 않는다.
