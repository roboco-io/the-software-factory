# P08 조합 단위의 선별

상태: 초고 · 저자 검토 대기 · 실제 업무 효과 미검증

## 상황과 반복되는 문제

공개 모델 정보만으로 실제 업무의 수행·비용·개입을 판단하기 어려운 상황에 적용을 검토한다. 모델 순위가 실제 프로젝트 성능을 예측하지 못한다. 이 문제를 결과·기준·권한의 연결에서 조사하며 개인이나 도구 하나의 결함으로 단정하지 않는다.

## 상충하는 요구

공정한 비교 조건을 유지할 요구와 각 조합의 고유 기능을 활용할 필요가 충돌한다. 실제로 줄일 부담과 새로 생기는 부담을 함께 관찰해야 한다.

## 해결 원리와 적용

대표 업무에서 모델과 에이전트와 하네스와 환경을 하나의 조합으로 평가한다. 이 원리는 이 책의 설계 제안이며 효과가 입증된 보편 법칙이 아니다.

대표 업무와 중요한 예외, 적격 기준을 먼저 정한다. 같은 조건에서 반복하고 결과·비용·개입과 환경 버전을 기록한다. 운영 변화와 실패에 따라 재평가할 조건을 둔다. 필요한 입력과 다음 판단의 책임을 정하고, 적용한 기준과 미검증 조건을 결과에 연결한다.

## 결과와 비용

비교 실험과 구성 유지에 비용이 든다. 기대한 이익은 실제 수용 결과와 전체 비용에서 확인한다. 기록과 검증·학습·이관에 추가된 부담을 활동량의 증가와 구분한다.

## 실패 경계와 적용하지 않을 조건

쉬운 과제나 평균 점수만으로 선정하면 경계 실패가 가려질 수 있다. 표본이 작거나 조건이 다른 결과를 일반적인 순위·동등성으로 확정하지 않는다. 적용할 범위를 정할 근거가 부족하면 먼저 작은 업무에서 조건을 조사한다.

## 검증 상태와 다음 판단

동일 과제의 수용률과 비용과 개입 시간 및 반복 편차를 비교한다. 적용 조건이 바뀌면 같은 기준의 비교가 가능한지 먼저 확인한다. 초고의 내용 검토와 실제 효과 평가는 다른 상태이며 저자 검토·현장 평가·편집 확정은 남아 있다.
