# P09 실행 주체의 교체

상태: 초고 · 저자 검토 대기 · 실제 업무 효과 미검증

## 상황과 반복되는 문제

현재 수행자가 중단되거나 새 조합·환경으로 바꿀 필요가 있는 업무에 적용을 검토한다. 도구 변경이 업무의 기준과 작업 기록을 깨뜨린다. 이 문제를 결과·기준·권한의 연결에서 조사하며 개인이나 도구 하나의 결함으로 단정하지 않는다.

## 상충하는 요구

전환 가능성을 확보할 요구와 고유 기능·기록 형식·재교육 비용이 충돌한다. 실제로 줄일 부담과 새로 생기는 부담을 함께 관찰해야 한다.

## 해결 원리와 적용

계약과 산출물 형식과 기록 인터페이스를 유지하며 실행 주체를 교체한다. 이 원리는 이 책의 설계 제안이며 효과가 입증된 보편 법칙이 아니다.

같은 계약·산출물·기록을 새 수행자가 사용할 수 있는지 확인한다. 현재 상태와 미검증·이미 한 행동을 인계하고 대표 업무에서 전환·회귀를 평가한다. 되돌아갈 조합의 적격성도 확인한다. 필요한 입력과 다음 판단의 책임을 정하고, 적용한 기준과 미검증 조건을 결과에 연결한다.

## 결과와 비용

공통 인터페이스를 유지하고 자료를 변환하며 전환과 회귀를 검증하는 비용이 생긴다. 모든 도구를 동일하게 추상화하면 고유 기능을 충분히 활용하지 못할 수 있다. 교체의 필요가 낮으면 과도한 공통화보다 현재 조합의 적격성과 복귀 조건을 유지한다.

## 실패 경계와 적용하지 않을 조건

공통 형식이 있다고 모든 수행자가 같은 능력을 갖지는 않는다. 자주 바꿀 이유가 없는 저영향 작업은 추상화의 추가 비용을 먼저 본다. 적용할 범위를 정할 근거가 부족하면 먼저 작은 업무에서 조건을 조사한다.
