# GA4 integration plan — 2026-10-15

## Goal and scope

사용자가 승인한 GA4 도입: 분석 동의 후 수집, 읽기 기록과 분리, 광고 기능 비활성, 조회·스크롤·외부 클릭은 향상된 측정으로, 추천 완료·추천 장 클릭·수동 읽음은 제한된 맞춤 정보로 측정한다. 사용자가 책 전용 GA4 속성으로 완전 분리를 선택했다. 새 속성 생성·측정 ID 확인 전에는 임의 속성을 사용하지 않는다. 미커밋 원고·리뷰 정책 변경은 이번 게시 범위와 분리한다.

## Architecture

- 순수 analytics.mjs: 별도 동의 상태·180일 유효기간·설정/호스트 검사·이벤트 허용 목록·수집 lifecycle. 외부 SDK와 DOM은 브라우저 어댑터에 격리한다.
- BookAnalytics.astro + analytics.ts: 공통 동의 배너·설정 버튼·태그 지연 로드. 거절 전/후에 태그를 로드하지 않는다. 철회는 collection disable·GA 쿠키 삭제·문서 재로딩으로 이미 로드한 SDK를 종료한다. 다른 탭 철회에도 같은 처리를 적용한다.
- 기존 reader/quiz는 완료 행동만 명시적 이벤트로 전달한다. DOM 표시·저장값 복원은 완료 이벤트가 아니다.
- PUBLIC_GA_MEASUREMENT_ID를 GitHub 변수로 연결한다. 미설정 시 수집은 꺼져 있고 공개 배포 활성화를 완료했다고 보고하지 않는다.
- 통계 안내 페이지·바닥글 설정과 운영 문서. 후속 사용자 지시로 향상된 측정은 유지한다. 조회·스크롤·외부 클릭은 자동 수집하고 추천·읽음 관련 3개만 직접 전송해 중복을 피한다. 광고 기능·Google signals는 사용하지 않는다.
