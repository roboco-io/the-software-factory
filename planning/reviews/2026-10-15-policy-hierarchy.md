# 정책 계층·하네스 사이클 반영 및 변경 범위 점검

- 날짜: 2026-10-15. 기준과 전후 해시: [manifest](2026-10-15-policy-hierarchy-manifest.json).
- 요청: 정책을 에이전트의 작업 지침으로 정의하고 비타협적 최상위 원칙·적용 범위별 정책을 본문과 최신 도표로 연결한다. 저자 결정 D30.
- 적용 기준: planning/review-policies/의 현행 정책과 용어집. 작성 에이전트의 변경 범위 자기 점검이며 네 축 독립 리뷰나 편집 확정은 아니다. 다른 작업의 리뷰 결과는 변경 문단에 자동 승계하지 않는다.

## 논증과 변경

| 중심 장 | 주장과 리더의 결정 | 비용·관찰 |
|---|---|---|
| 3장 | 정책은 작업 지침이다. 원칙 아래 적용 범위·강제성·변경 권한을 정한다. | 중복 문구·상속 충돌·해석 대기를 관리하고 미해결 충돌의 보류·이관을 확인한다. |
| 9장 | 정책→계획과 집행→실행 이력→모니터링·개선을 연결한다. | 원칙은 자동 완화 대상에서 제외한다. 실제 적용·차단·미검증·외부 신호의 연결을 본다. |
| 19장 | 하위 지침 보완과 집행 개선을 구분한다. | 모호성인지 미준수인지 진단하고 권한·근거·보존할 원칙을 변경 이력에 남긴다. |

1·2·4·7·11장, 서문, P02·P10·P15와 홈·기획·용어집을 연결했다. 검증 정책이라는 부분 용어와 기존 판정자·수용 책임자·수행자 구분은 유지했다. 패턴 카탈로그의 ID·이름·정의는 변경하지 않았다. 신규 도표 두 개는 원고 SVG가 기준이며 웹에는 같은 파일을 복사한다.

## 근거와 수용 조건

저자 첨부 이미지와 직접 설명을 확인했다. Artifact URL 전체는 접근하지 못했으므로 통독으로 기록하지 않았다. [편집 메모](../../research/policy-hierarchy-editorial-note.md)와 출처 대장의 author_material_checks에 한계를 남겼다. 새 효과 수치·실제 운영 성과·외부 자료의 정책 계층 정의는 주장하지 않았다.

| 점검 항목 | 결과 |
|---|---|
| 정책을 검증 전체와 동일시하지 않음 | 3·7·9장 및 용어집 대조 완료 |
| 하위·최신 지침이 상위 원칙을 무효화하지 않음 | 3·9·19장과 두 도표 대조 완료 |
| 적용 범위와 강제성 구분, 충돌 시 보류·이관 | 3장 본문·표·도표 설명 대조 완료 |
| 모호한 지침과 명확한 지침의 미준수 구분 | 19장 대조 완료 |
| 도표 가독성 | SVG 원본·390px 모바일·1065px 화면 시각 점검; 글자·연결선·캡션·확대 링크 확인 |
| 반응형 | 수정 전 모바일 776px 넘침 재현, 이미지 max-width 수정 후 390·1065px 넘침 없음 |
| 기존 anchor와 읽기 상태 | 기존 모든 anchor ID 유지, 지정 12페이지 revision만 +1, 저장 키·스키마 유지 |

## 실행 검증과 남은 범위

구조 검사 통과(20장·15패턴·97출처), 단위 25개 통과, Astro 진단 0건, 47페이지 빌드·내부 링크·anchor 검사 통과. 브라우저 23개 통과·1개 의도적 건너뜀(모바일 전용 표 검사의 데스크톱 실행). 새 도표의 경로 허용 목록과 원본 링크도 검사했다.

이 변경 범위에서 미해결 P0·P1을 발견하지 않았다. 전체 책의 네 축 리뷰 완료나 저자 최종 편집 승인을 뜻하지 않는다. 정책 계층의 실제 조직 운영 효과는 검증하지 않았다. 커밋·푸시·배포는 수행하지 않았다.
