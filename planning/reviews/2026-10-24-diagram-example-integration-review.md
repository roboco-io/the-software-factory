## 데모 근거와 한계

데모의 기준 판본 `5b1927f8328266070c3d0bf98bac194dc21df012`를 유지했다. GitHub 연결 도구로 S98 README의 개요·흐름, S103 워크플로 전체·protect 코드 전체·implement의 계획/prepare/agent/publish와 보호 함수 연결 부분·운영 안내의 관련 한계와 보안 절을 다시 읽었다. 그림의 토큰·전달물·검사 관계를 대조했다. 최신 브랜치 전체와 비교해 사례 판본을 올리는 작업은 하지 않았다.

위험 판정·수정 증거·복구·지표·평가 표는 기존 해설을 재구성했다. 해당 코드를 전부 새로 실행·재검증한 것으로 표시하지 않는다. S98/S103의 후속 확인·자체 도식 사용 범위를 출처 대장에 덧붙이고, 새 출처 ID 없이 [주장 메모](../../research/claims/diagram-example-integration.json)에 사실/설명 예시/저자 제안을 구분했다. 기존 문서·코드의 Apache-2.0 사용 근거를 유지하며 원문 전문·제3자 이미지를 복제하지 않았다.

- 기존 절 제목·안정 앵커는 모두 보존했다. 추가 그림은 별도 `fig-*` 앵커로 연결하며 기존 절 토론 단위는 바꾸지 않았다.
- 변경한 독자 페이지의 내부 읽기 revision을 이번 반영분만 한 단계 올렸다. 책 버전 번호로 표시하지 않는다.
- 도표는 `manuscript/figures/catalog.json`의 허용 목록을 링크 변환과 복사가 함께 사용한다. 미등록 SVG와 경로 이탈은 공개 링크로 바꾸지 않는다. 기존 테스트를 이 목록 전체로 확장했다.
- 새 SVG 전체의 XML과 실제 브라우저의 글자 경계를 확인하고 그림을 시각 점검했다. 의도/하네스 루프의 분기·환류, 도입 경로 합류, 복구/자동화 분기를 조정했다.
- [브라우저 점검 기록](2026-10-24-diagram-example-browser.json): 변경 35페이지 × 데스크톱/모바일 2종. 이미지 로드·대체 설명·페이지 가로 넘침 부재·토론 링크를 확인했다. 핵심 도표와 모바일 계약·비교 표 화면도 읽었다.

## 판정과 인계

제안서의 핵심·선택 보강을 원고와 웹 생성물에 반영했다. 장식 삽화 보류와 이전 미커밋 서문/공유 메타데이터 수정은 보존했다. 중요한 이해 보강이므로 독자용 체인지 로그의 ‘공개 예정’에 한 항목으로 묶었다. 커밋·푸시·공개 배포는 수행하지 않았다.
