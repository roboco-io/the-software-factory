# Code Review 공식 문서 대조의 원고 반영 검토

## 범위와 판본

저자의 ‘원고도 수정해줘’ 요청을 앞선 [비교 보고서](../../research/claude-code-review-comparison-2026-10-27.md)의 우선 제안 CR01·CR02 반영으로 적용했다. 7장의 리뷰·증거 구분과 12장의 리뷰 출력·반영 권한을 보강했다. CR03·CR04는 선택 제안으로 유지하고 다른 장에 같은 내용을 반복하지 않았다.

검토 기준은 집필 지침, 원고 리뷰의 논증/독자 기준, 완전 자동화 기준과 체인지 로그 정책이다. 실제 비교에 사용한 공식 문서 S139·S141과 기존 S112의 범위는 앞선 비교의 출처 기록을 사용한다. 문서를 새로 실행하거나 업체 내부 운영을 검증하지 않았다. 기준 HEAD와 수정 전 해시는 비교 주장 메모, 수정 후 해시는 [반영 판본](2026-10-27-code-review-manifest.json)에 보존한다. 앞서 진행한 화살표 수정과 홈의 서문 연결 변경은 보존했다.

| 대상 | 중심 주장 | 리더의 결정 |
|---|---|---|
| 7장 | 지적의 타당성과 실행에서 관측한 사실, 결과의 수용은 서로 다른 판단이다. | 작업 계약에 맞는 증거 조합과 수용 범위를 정한다. |
| 12장 | 리뷰가 남기는 출력과 실제 병합을 허용하는 정책·권한은 다르다. | 필수 증거의 유효성과 미확인 경로를 실제 반영 조건에 연결한다. |

## 의견별 수정 검증

| ID·등급·상태 | 위치·독자 영향 | 최소 수정·수용 조건 | 자기 점검 |
|---|---|---|---|
| CR01·P2·반영 검증 완료 | 7장 「리뷰를 수행 중의 검사와 수용 판단으로 나눈다」. 지적 검증이 빌드·실행까지 포함한다고 오독할 수 있다. | S139의 제품 범위를 S112 내부 운영과 구분하고 지적 확인/실행 검증/수용 판단의 세 질문을 표시한다. 필요한 증거는 계약에 맞게 고른다. | 제품 기능 문단과 저자 제안 표를 구분했다. 정적 검토가 무가치하다거나 모든 작업에 같은 테스트를 요구한다는 주장으로 확대하지 않았다. |
| CR02·P2·반영 검증 완료 | 12장 「변경의 위험과 현재 증거를 병합 판단에 연결한다」. 비차단 제품을 사람의 매회 승인 의무나 자동 통과로 오해할 수 있다. | S141의 출력/연동 범위를 설명하고, 현재 변경에 유효한 결과와 필수 증거를 자동 반영 정책에 연결한다. 결과 누락은 0건으로 처리하지 않는다. | 정책이 허용한 무승인 자동화와 사람에게 유보한 판단을 유지했다. 필수 판정의 미수행·시간 초과·취소·누락·유효성 미확인을 보류/허용된 재검증·예외 경로로 연결했다. 필수가 아닌 검토를 일률적인 대기로 바꾸지 않았다. |

서비스가 이전 결과를 재사용할 수 있다는 문서의 조건과 충돌하지 않도록, ‘현재 SHA에서 반드시 새 리뷰를 실행’이라는 규칙을 추가하지 않았다. 다른 버전의 결과라면 현재 변경에도 유효한지 확인해야 한다는 기준으로 썼다. 그 유효성을 확인하지 못한 경우와 결함 없음의 판정을 구분한다.

이번 수정은 두 의견에 대한 내용·연결의 자기 검증이다. 전체 원고의 사실 리뷰나 독립 검토·실제 독자 시험·저자 최종 편집 확정으로 표시하지 않는다. 새 P0/P1 의견을 판정하는 검토는 수행하지 않았다.

## 근거·구조·화면 확인

- 7장 S139, 12장 S141의 출처 표식·대장·장별 주장 메모를 연결했다. S112는 내부 운영의 출처로 유지한다. S140·S142를 본문에 새로 인용하지 않았다.
- 직접 인용·제품 설정 명령·성과 수치는 추가하지 않았다. 비교 보고서와 새 본문의 출처 표시 문단 및 최소 메모를 합산하는 사용 범위를 대장에 기록했다.
- 두 장의 제목·기존 안정 앵커·토론 단위는 유지했다. 읽기 revision은 두 장만 각각 한 단계 올렸다. 중요한 설명 보강이므로 체인지 로그는 ‘공개 예정’에 한 항목을 추가했다.
- `python3 scripts/check_project.py`: 20장·15패턴·142출처, JSON과 로컬 연결 통과.
- `npm --prefix website run build`: 56페이지·본문 인용 출처96개 생성, 내부 링크/앵커 검사 통과.
- 실제 로컬 7·12장 × 데스크톱/모바일 4회 점검에서 새 문구·출처·절/토론 링크·페이지 가로 넘침 부재를 확인했다. 7장 표는 모바일 화면으로도 읽었다. [화면 결과](2026-10-27-code-review-browser.json).
- 원고/출처/독서 메타데이터의 변경이므로 소프트웨어 동작 테스트를 새로 만들지 않았다. 빌드·구조·출처 연결과 해당 화면 확인에 검증 범위를 한정했다.

## 판정과 인계

CR01·CR02 반영과 해당 변경의 자기 검증을 마쳤다. 원고의 허용 범위 내 완전 자동화 원칙과 검증 독립성의 정의는 유지한다. CR03·CR04는 필요 시 기존 정책·지표 설명에 연결할 선택 후보로 남긴다. 공개 배포·커밋·푸시는 수행하지 않았다.
