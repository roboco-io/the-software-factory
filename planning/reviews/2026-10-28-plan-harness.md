- 요청: 책 전체에서 실행계획을 이번 작업의 경로로, 하네스를 정책에 따른 수립·집행·기록·관찰·개선의 전체 체계로 구분한다(D57).
- 기준 HEAD: `0b6d911a273c874858016c47a9e728cbf0626e75`. 시작 작업 트리는 깨끗했다. 전후 해시는 함께 저장한 매니페스트에 있다.
- 적용: AGENTS.md, 집필 기획, 목차, 패턴 카탈로그, 용어집, 편집·근거 정책, 현행 리뷰 정책의 논증·독자·출판 기준, chapter-tldr 및 book-changelog 정책. 리뷰 정책은 저자 편집 확정 전 기준이다.
- 실제 확인: 서문·20장·15패턴·데모 해설 전체의 계획/하네스 관련 용례를 검색하고 해당 문단을 대조했다. 1·2·3·4·7·9·11·12·19장의 본문과 TL;DR을 읽고 변경 대상 문단을 깊이 대조했다. 나머지 11장은 관련 용례의 문맥과 비변경을 확인했으며 전체 내용·모든 외부 사실의 재검증으로 보고하지 않는다.
- 도표: 전체 목록에서 계획/하네스 용례를 확인하고 1·4·9장 SVG 세 개를 수정했다. 본문·캡션·대체 텍스트·SVG 설명·목록을 연결했다. 화살표 경로는 보존했다.

## 의견과 수정 검증

### PH01 / P1 / 검증 완료(변경 범위 자기 점검)

- 위치/버전: 기준 HEAD의 3장 ‘정책은 경계를 정하고 계획은 경로를 선택한다’, 9장 ‘하네스의 네 단계를 하나의 책임 흐름으로 묶는다’.
- 문제/독자 영향: 실행계획이 정책을 집행하는 기반 자체처럼 읽히며 ‘계획과 집행’이 결과물인 계획과 실제 통제 기능을 묶었다. 계획서 작성만으로 정책이 집행된다고 오해할 수 있다.
- 근거/확인 수준: 현재 본문과 저자 D57의 정의 대조. 외부 사실 판정이 아닌 개념·논증 점검이다.
- 최소 수정: 3장에 네 개념의 같은 업무 비교 예시와 문서/집행의 구분을 추가했다. 9장 두 번째 단계는 ‘계획 수립·집행’으로 명시하고 각 기능과 운영 책임을 나눴다. 서문·1·2·7·11·12장·P02·홈·용어집·현행 집필/리뷰 기준을 맞췄다.
- 수용 조건/증거: 작업 경로와 실제 실행·통제·기록·개선 체계를 각각 설명하고, 계획 조정이 보호 장치 변경 권한으로 확대되지 않아야 한다. 수정 본문과 표·요약에서 이 구분을 다시 읽어 확인했다. 정책이 허용한 개별 승인 없는 자동화와 상위 원칙은 보존했다.

## 판정과 인계

위 세 의견은 해당 수정의 자기 점검으로 닫았다. 전체 원고 편집 확정·독립 리뷰·외부 원문 재대조·실제 운영 효과 검증은 수행하지 않았다. 새 본문과 요약은 이전 버전 리뷰 판정을 자동 승계하지 않는다. TL;DR은 9장을 재검토해 8장 문구를 수정하고, 7장은 내용 요약이 그대로 유효함을 확인해 이유와 새 본문 판본만 갱신했다. 나머지 11장 요약은 본문과 함께 변경하지 않았다.

독자 체인지 로그는 공개 예정에 한 항목을 추가했다. 이전 TL;DR 배포 대기 기록이나 공개 예정 항목을 이번 작업으로 공개 완료 처리하지 않았다. 커밋·푸시·배포는 이번 요청에서 실행하지 않는다. 기계 검사와 화면 확인 결과는 매니페스트·브라우저 기록·세션 기록에 남긴다.
