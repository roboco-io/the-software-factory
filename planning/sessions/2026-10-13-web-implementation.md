# 2026-10-13 웹 독서판 구현

## 범위와 기준

저자가 제안 방향에 따라 Astro Starlight, 질문 기반 추천과 localStorage 읽기 진도 구현을 요청했다. 기준 HEAD d99a03c. 시작 시 웹 공개 조사·출처·제안 기록이 미커밋 상태였으며 보존했다. 실제 공개 도메인·호스팅 연결·커밋·푸시는 수행하지 않았다.

## 구현

- website 디렉터리에 Astro 7.3.8 / Starlight 0.42.6 앱을 추가했다. 설치 시 npm의 peerDependencies를 확인하고 lockfile을 저장했다.
- 원고 원본을 수정하지 않고 서문·20장·15패턴을 생성한다. 장별 공개 URL, 이전/다음·절 목차·고정 읽기 앵커·패턴 연결·참고문헌을 제공한다.
- 홈·전체 목차·추천·패턴 목록·소개/설정·404까지 43개 HTML 페이지를 만들었다. 본문이 실제 인용한 67개 출처의 공개 필드만 발행한다. 이후 출처 수는 원고에 따라 달라질 수 있다.
- 목적·역할·깊이의 3문항으로 6개 경로를 추천한다. 목적은 장 순서를, 역할은 해당 경로의 강조를 정한다. 깊이는 핵심 판단/본문 진입을 결정한다. 답변 변경·초기화·건너뛰기·전체 목차 이동을 제공한다.
- 방문은 읽는 중으로, 읽음은 독자의 버튼으로 기록한다. 같은 브라우저의 마지막 장·고정 절·절 안 비율·읽은 판본·추천 답변·글자 크기를 저장한다. 장 안과 홈에서 이어 읽기를 제공한다.
- 저장 켜기/끄기·전체 초기화, 저장 접근 차단/쓰기 실패·손상된 상태·다중 탭 갱신·직접 앵커 우선·의미 있는 개정 표시를 처리한다.
- 공개 내부 링크는 명시한 경로만 변환하고 알 수 없는 경로는 빌드 오류로 처리한다. STATUS·planning·research/claims를 복사하지 않는다. 출처의 날짜·확인 범위·한계는 보존한다.
- 기존 scripts/check_project.py는 node_modules·dist·.astro 및 재생성 원고를 제외하도록 조정했다. 웹 산출물은 별도 검사한다.

## 검증과 리뷰

- 실패하는 단위 테스트부터 추천·출판 변환·진도 저장을 구현했다. 최종 `npm test`: 13/13 통과. 모든 목적×역할×깊이 조합을 검사한다.
- `npm run check`: 오류 0·경고 0·힌트 0.
- `npm run build`: 43개 페이지, 20장·15패턴 존재와 공개 내부 링크·앵커 검사 통과. 내부 검토 파일 경로 노출 없음.
- `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`: 데스크톱·모바일 설정에서 12/12 통과. 추천→읽음→다시 열기→답변 변경, 두 탭 초기화·끄기, 저장 차단, 화면 폭·키보드, 검색 인덱스, 현재 장의 이어 읽기를 확인했다.
- 한국어 검색은 의도·실행 계약·P07·책임의 결과 존재를 빌드된 Pagefind 인덱스로 확인했다. 언어학적 검색 품질의 전체 평가는 아니다.
- 홈·추천·7장 스크린샷을 생성하고 데스크톱 홈·모바일 홈·모바일 장을 시각 확인했다. 실제 iPhone/Safari 시험은 아니다.
- requesting-code-review 스킬에 따른 별도 코드 리뷰에서 P2 세 건 발견: 쓰기 실패 후 메모리 기록 유실, 맨 위 위치의 이전 절 잔존, 장 안의 이어 읽기에서 pagehide가 북마크 덮어쓰기. 재현 단위 테스트 2개와 브라우저 회귀를 추가해 수정했고 리뷰어 재검토도 완료했다.
- CSS 빌드 의존성의 GHSA-rj75-hqrm-r3gf를 postcss-selector-parser 7.1.6 override로 조치했다. `npm audit --audit-level=moderate`: 알려진 취약점 0. fsevents 선택적 설치 스크립트는 승인하지 않았으며 빌드·검증에 필요하지 않았다.
- 구성 검사와 빌드는 공유하는 Astro 캐시 때문에 순차 실행한다. 최초 병렬 실행의 캐시 충돌 뒤 순차 재검사에서 통과했다.

## 운영과 남은 범위

[실행·개정·배포 안내](../../website/README.md)를 따른다. 실제 도메인을 정한 뒤 SITE_URL을 설정하고 dist만 배포한다. 현재 주소는 로컬 미리보기 `http://127.0.0.1:4321/`다. 계정·DNS·외부 공개 배포는 미수행이다.

현재 저장은 origin·브라우저 프로필별이며 다른 기기와 동기화하지 않는다. 저장소가 차단되면 페이지 메모리만 사용하며 안내한다. 다중 탭의 변경은 반영하되 완전 동시 쓰기의 트랜잭션 보장은 없다. 추천의 독자 이해·실제 효용은 독자 검토 대상이다. 원고의 편집 확정이나 운영 효과 검증을 이 구현으로 승격하지 않는다.
