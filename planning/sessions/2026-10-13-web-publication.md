# 2026-10-13 웹 공개 형식 조사와 독서 안내 제안

- 요청: 원고의 웹 공개 형식 조사·제안, 쿠키를 통한 읽기 진도 편의. 후속: 역할·목적 질문에 따른 장 추천 검토.
- 확정 응답: 로그인 없이 같은 브라우저에서 이어 읽기.
- 조사: Exa의 3각도 검색 결과 12건, 공식 원문 14개 URL 관련 부분, Context7의 Starlight 확장 경로. Exa 호출 3회는 필수 인자 누락으로 실패한 뒤 수정했고 결과 수에서 제외했다. 외부 원문 저장·브라우저 시각 검증·설치·서비스 실행·배포는 하지 않았다.
- 자료: S76~S88 등록. 기존 75개 출처·원고·패턴 변경 없음. 웹 출판 조사와 원고의 논증 근거를 구분했다.
- 제안: [온라인 책·패턴 사전·선택형 독서 안내](../web-publication-proposal.md). 역할보다 목적을 우선하고 읽기 깊이를 선택한다. 원고의 장 번호·리더 결정과 6개 초기 경로를 대조했다.
- 저장: localStorage를 권장하고 쿠키만 쓰는 대안의 비용을 비교했다. 자동 위치 기록과 독자의 읽음 표시를 구분하고 개정·저장 차단·초기화 조건을 명시했다. 기술 선택은 제안이다.
- 확인: 구조 검사 PASS(20장·15패턴·88출처), 기존 원고·카탈로그 보존과 경로의 장 번호, 새 출처/주장 연결을 확인했다. 제안의 기술적 성능·추천 효과·실제 독자 검증은 미수행이다.
- 다음: 제안 형식을 바탕으로 한 장·한 패턴의 독서 화면을 구체화하고 전체 목차·검색·진도·추천으로 확장한다. 도메인·호스팅·공개판 표시와 이용 조건은 구현 전 결정 대상이다. 커밋·푸시하지 않았다.
