# 2026-10-14 체인지 로그 전환과 작성 스킬

## 요청과 반영

저자는 책의 버전 번호가 의미 없으므로 릴리즈 노트를 체인지 로그로 바꾸고, 사소한 오타·변경 대신 독자가 알아야 할 중요한 내용만 선별할 정책과 스킬을 요청했다.

- RELEASE_NOTES.md를 CHANGELOG.md로 옮기고 실제 첫 공개일과 중요한 내용을 날짜 중심으로 보존했다. 공개 UI의 0.1 프리뷰는 제거하고 공개 초안 상태를 표시한다.
- book-release.json은 book-publication.json으로 바꾸고 버전·날짜 필드를 제거했다. 도메인·피드백·공개 상태만 보관한다. 내부 기획·코드 버전과 장별 읽음 revision은 유지한다.
- 웹 /changelog/와 탐색·바닥글·소개를 연결했다. 기존 /releases/는 새 페이지로 안내하며 읽음 기록을 초기화하지 않는다.
- 정책은 skills/book-changelog/references/policy.md, 스킬은 skills/book-changelog/SKILL.md다. AGENTS·README에 적용 기준을 연결했다. Codex 개인 스킬 경로에도 설치해 같은 정책을 사용할 수 있게 했다.

## 선별 기준과 적용

‘이 변경을 모르면 독자의 이해·판단·사용에서 중요한 차이를 놓치는가’를 기준으로 삼았다. 변경량과 파일 수는 기준이 아니다. 중요한 변경이 없으면 로그를 수정하지 않는 것이 정상이다. 사실·권한·책임을 바꾸는 작은 정정은 포함하고, 의미가 같은 오탈자·문장 다듬기·내부 도구 유지보수는 제외한다. 완료·공개 상태와 실제 날짜를 확인하며 커밋·빌드·스킬 작업을 공개 로그에 나열하지 않는다.

합성 사례로 정책의 경계를 수동 대조했다. 실제 독자 시험이나 별도 모델의 행동 평가로 표시하지 않는다.

| 합성 변경 | 판정 | 이유 |

| 코드 리팩터링·패키지 버전 갱신 | 제외 | 내부 유지보수만 변경 |

이번 적용에서는 기존 공개판의 주요 설명·독서 기능·라이선스를 유지했고, 스킬 제작·버전 표시 제거·순수 URL 정리는 별도 공지 항목으로 만들지 않았다. 실제로 공개된 데모 화면 링크를 공통 예시 안내에 붙였다.
