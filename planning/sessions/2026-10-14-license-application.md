# 2026-10-14 라이선스 적용

저자가 제안한 본문 CC BY-SA 4.0·웹 코드 MIT 적용과 사이트 표시를 지시했다. 저작권 고지는 책의 저자 정도현, 연도 2026으로 표기했다. [적용 범위](../../LICENSE.md)에 책 원고·패턴·도표 및 변환 콘텐츠, 직접 작성한 웹 코드·스타일·설정·도구·테스트를 구분했다. 제3자 자료와 범위 밖의 내부 문서는 별도로 다룬다.

CC 공식 전문은 변형 없이 저장했고 MIT 표준 전문에 저작권 고지를 넣었다. 사이트의 모든 페이지 바닥글·소개·라이선스 안내에서 조건을 연결한다. 독립 정적 산출물에서도 전문을 읽을 수 있도록 빌드 시 public/licenses에 복사한다. Astro·Starlight·Pagefind의 기존 라이선스 고지도 그대로 포함한다. 기존 제안·주장 메모와 S89/S93 확인 기록을 갱신했다.

기존 원고·웹 변경을 보존했다. 실제 외부 도메인 배포·커밋·푸시와 개별 제3자 권리 귀속의 법적 검토는 수행하지 않았다.

- 검증: 웹 44페이지 빌드·링크/앵커, Astro 오류/경고 0, 프로젝트 구조 검사 통과. 모든 페이지의 두 라이선스 표시와 배포 전문의 바이트 일치, MIT 패키지 메타데이터를 확인했다. 브라우저 미리보기에서도 두 표시를 확인했다.
