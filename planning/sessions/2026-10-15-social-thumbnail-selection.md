# 2026-10-15 SNS 공유 이미지 선택

저자가 로보코 로고를 사용한 네 후보 중 2번 아이보리 미니멀을 선택했다. 선택한 PNG를 website/public/images/software-factory-social-ivory.png로 복사하고 Open Graph·Twitter 이미지 URL과 실제 크기(1734×907)를 갱신했다. 다른 후보와 이전 이미지 파일은 보존한다. 새 URL을 사용해 기존 이미지 URL의 캐시와 구분한다. SNS 사업자의 캐시 갱신 시점은 직접 제어하지 않는다.

기존 원고·리뷰 정책의 미커밋 작업은 별도로 유지한다. 이번 커밋·공개 반영 범위는 이미지·공유 설정과 이 세션 기록이다. 선택된 이미지 원본을 시각적으로 확인했으며 별도 재생성·편집은 하지 않았다. 공개 기준 원고에서의 빌드와 실제 HTTP 확인 결과는 아래에 기록한다.

검증: 공개 기준 HEAD를 /tmp에 추출하고 썸네일·공유 설정만 적용한 환경에서 원고 구조(20장·15패턴·97출처), 단위 13개, Astro 진단 0건, 46페이지 빌드·링크 검사 통과. 의존 파일의 심볼릭 링크 때문에 발생한 첫 빌드 경로 오류는 파일 복사 후 해소했다. 홈·1장의 Open Graph·Twitter 새 이미지 URL과 실제 크기를 대조했다.
