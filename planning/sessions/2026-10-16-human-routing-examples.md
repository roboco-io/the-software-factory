# 사람 확인 필요 여부를 분류하는 두 예시

- 저자 요청 D37: 권한 설정 변경의 명시적 규칙 분류와 비용 트레이드오프의 LLM 문맥 분류를 설명한다.
- 범위: 3장의 정책 표현 절에 비교표와 설명을 추가하고 12장의 실제 권한 집행에 연결했다. 자동화 범위 기준과 두 장의 주장 메모를 갱신했다. 이전 미커밋 작업은 보존했다.
- 중심 결정: 사람 확인 필요 여부의 자동 분류와 최종 승인 권한은 다르다. 조직이 사람 확인을 의무화한 권한 변경은 규칙으로 확인 대기에 보낸다. LLM은 비용·품질·응답 시간의 영향을 해석해 위임 범위를 넘는 판단을 이관할 수 있지만 명시적 사람 확인 의무를 해제할 수 없다.
- 자기 점검: 권한 변경은 모든 조직의 보편적 승인 의무가 아닌 정책 예시로 한정했다. 비용 판단 역시 모두 사람에게 넘기지 않고 기존 허용 범위 내 자동 처리를 유지했다. 분류 미확인은 자동 승인하지 않는다. 외부 관측 사실·실행 효과를 추가하지 않았으며 새 외부 조사는 없다.
- 검증: 구조 검사 20장·15패턴·111출처, 56페이지 빌드 및 내부 링크·앵커 검사, 공백 검사 통과. 이번 추가는 산문·표 변경이므로 브라우저 전체 시험은 재실행하지 않았다. 독립 리뷰·실제 정책 엔진 실행·독자 이해 시험은 아니다.
- 기존 앵커 유지, ch03/ch12 revision만 직전 미커밋 판본에서 1 증가했다. 커밋·푸시·배포하지 않았다. 다음은 저자 확인 후 요청에 따른 게시다.
