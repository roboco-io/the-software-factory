- 사용자 요청: 지정한 1차 자료를 읽고 책에 반영한다.
- 범위: 7장 리뷰 시점·판정 근거, 12장 자동화/유보 권한과 제품/내부 운영 구분, 17장 대기/복구 비용, 19장 리뷰어 평가·반복 종료 조건. 새 사실의 상세 범위는 S112와 본문에만 기록했다.
- 출처 확인: S112 본문 전체 직접 확인. 이미지 도표·연결된 별도 글·내부 실행·독립 성과 검증은 제외. [조사 메모](../../research/anthropic-code-review-note.md).
- 검토: [변경 범위 자기 점검](../reviews/2026-10-17-anthropic-code-review.md)·[전후 해시](../reviews/2026-10-17-anthropic-code-review-manifest.json). 사례는 업체 자체 보고, 후속 권고는 저자 해석/설계 제안으로 구분했다.
- 검증: 구조 20장/15패턴/112출처, 56페이지 빌드와 내부 링크·앵커 검사, 공백 검사 통과. 기존 출처 객체와 앵커 보존, 수정 네 장 revision 증가 확인. 실행 동작을 바꾸지 않은 산문 변경이므로 브라우저 전체 시험은 재실행하지 않았다.
- 이전 미커밋 작업을 보존했다. 체인지 로그는 공개 예정이며 커밋·푸시·배포하지 않았다. 독립 리뷰·편집 확정·실제 자동화 효과 승인은 아니다. 다음은 저자 검토 후 별도 요청에 따른 게시다.
