# claude.dev 멀티 에이전트 조사

- 요청: 다른 글을 읽고 소프트웨어 팩토리 책의 반영 후보를 찾는다. 세 하위 에이전트와 주 에이전트로 분담했다.
- 결과: 11편 원문 확인, S113~S123 등록, 후보 주장 메모와 네 담당 메모 작성. [통합 제안](../../research/claude-dev-survey-2026-10-17.md)에 우선순위·장/절·기존 설명 대비 가치·보류 이유를 기록했다.
- 범위: 홈페이지와 검색에서 선택한 글이며 사이트 전수 조사가 아니다. 원문 자체 보고와 저자 해석 후보를 구분했고 외부 링크의 코드·영상·실행·독립 효과 검증은 하지 않았다. 주 에이전트는 담당 보고와 주요 원문 절을 대조했다.
- 원고·패턴·웹·체인지 로그·페이지 revision은 변경하지 않았다. 기존 미커밋 작업을 보존했다. 구조·출처 객체 보존·공백 검사로 조사 파일 연결을 확인하며, 사이트 빌드·전체 브라우저 시험은 이번 조사에 필요하지 않아 재실행하지 않는다.
- 다음: 통합 제안의 우선순위대로 채택 시 해당 장의 중복과 출처별 누적 사용량을 재검토한다. 커밋·푸시·배포·편집 확정은 하지 않았다.
