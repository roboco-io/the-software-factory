# Language Benchmark를 기존5장에 반영

- 요청: 11장을 중심으로17·7·12·19장에 통합하고 중복과 사실/해석 혼동을 줄인다.
- 수행: 11장에 중심 절을 추가했다.17장의 일반 비용 충돌,7장의 증거 범위,19장의 일반 실패 조사 문단은 교체·통합했다.12장은 단계별 권한 집행으로 연결했다. 기존 조사 수정은 보존했다.
- 근거: S124 고정판본의 이전 확인 범위를 사용했다. 자체 보고/집계 대조와 저자 제안을 분리하고 실제 재현·일반 효과·실제 비용을 주장하지 않았다. 원고 출처 대장과5개 주장 메모 및 조사 카드 후속 상태를 갱신했다.
- 검토: [변경 범위 자기 점검](../reviews/2026-10-19-language-benchmark-adoption.md)·[전후 해시](../reviews/2026-10-19-language-benchmark-adoption-manifest.json). 구조20장/15패턴/124출처·56페이지빌드/내부링크/앵커·공백·생성 본문 확인을 수행한다. 기존 앵커 유지, 수정5장 revision 증가 확인. 실행 로직을 바꾸지 않아 브라우저 전체 시험은 재실행하지 않는다.
- 상태: 로컬 초안. 독자용 체인지 로그는 공개 예정이며 커밋·푸시·배포하지 않았다. 독립 리뷰·편집 확정·실험 실행은 아니다. 다음은 저자 검토 후 요청에 따른 게시다.
