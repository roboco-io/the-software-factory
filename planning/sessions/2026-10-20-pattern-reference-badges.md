# 본문의 패턴 링크·배지

- 사용자 요청:13장의P14를 패턴 사전에 연결하고 책의 다른 패턴 언급도 링크·배지로 표시한다.
- 수행: 웹 생성 단계에서 카탈로그에 등록된P01~P15의 본문·표/목록 언급을 링크로 바꾼다. 번호와 정식 이름이 함께 있으면 같은 링크에 묶는다. 기존 패턴 링크에도 배지를 붙이고 장 요약의 패턴 링크에도 같은 표시를 추가했다. 원고 텍스트는 일괄 치환하지 않았다.
- 보호 범위:코드·인라인코드·제목·정의·이미지·외부링크·원시HTML은 보존한다. 알 수 없는ID를 임의 연결하지 않으며 중첩/중복 링크를 만들지 않는다. 패턴 카드의 제목은 기존 구조를 유지한다.
- 구현: Markdown AST의 원문 위치만 패치하여 문서 구성을 유지한다.이미 설치되어 잠금된mdast-util-from-markdown2.1.0을 직접 의존성으로 명시했다.새로운 패키지 버전의 추가해결은 없고lock의루트선언만 바뀐다. 최초오프라인갱신은 메타데이터캐시누락으로 실패했고,실행스크립트/감사없이 lock만갱신하는 명령으로 완료했다.
- 검증: 새 테스트3개가 기존 구현에서 실패함을 확인한 뒤 구현했다. 단위33통과·Astro오류/경고/힌트0·56페이지빌드/내부링크·브라우저31통과/의도적skip1.본문/서문/15패턴/9데모의45페이지에서161링크·배지와 미연결ID/중첩링크0건을 정적 확인했다.코드/원시HTML 보호테스트도 통과했다.
- 시각 확인:13장 해당 문단을390px어두운테마와1065px밝은테마에서 캡처해 확인했다. 링크 이동·포커스·접근가능이름·모바일폭을 브라우저로 시험했다. 검색에는 배지글자를 추가하지 않도록 처리했다.
- 읽기상태: 의미가 같은 표현/탐색 변경이므로 이 작업은 본문anchor/revision을 바꾸지 않았다. 이전 미커밋1장·9/12장수정과 출처126개는 보존했다. [검증manifest](../reviews/2026-10-20-pattern-reference-badges-manifest.json).
- 공개상태:체인지로그공개예정.커밋·푸시·배포하지 않았다.다음은 사용자확인 후 별도요청에 따른 공개다.
