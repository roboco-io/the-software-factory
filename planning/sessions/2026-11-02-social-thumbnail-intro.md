# 2026-11-02 SNS 공유 썸네일에 책 소개 추가

## 요청과 판단

사용자가 LinkedIn 게시물 화면을 보여 주며 썸네일에 책 소개가 들어가게 해 달라고 요청했다. 2026-10-24에는 이미지를 바꾸지 않고 공유 제목·설명 메타데이터만 보강했지만, 해당 화면의 LinkedIn 링크 카드는 이미지·제목·도메인만 표시하고 설명을 보여 주지 않았다. 그래서 이번에는 이미지 자체에 소개 문구를 넣었다. 사용자가 시안을 확인하고 적용·배포를 승인했다.

## 변경

- 새 이미지 `website/public/images/software-factory-social-intro.png`(1734×907, SHA-256 `94d2d00a664e3517326d8a69646337cea63bf9be6d48b76d996fcac0c4e6c0f9`)를 추가했다. 기존 코발트 이미지(`software-factory-social-cobalt.png`)를 원본으로 삼아, 왼쪽의 제목·부제 블록(x 60-935, y 80-690)을 80%로 줄이고 그 아래에 소개 두 줄을 Pretendard SemiBold 38px, 색 `#D6E4FF`로 넣었다. 오른쪽 일러스트, 로보코 로고, 저자·도메인 표기는 바꾸지 않았다.
- 소개 문구는 `book-publication.json`의 책 설명을 줄인 것이다.
  - "비즈니스 목표 중심의 개발·운영·개선 자동화"
  - "SDLC 보안 내재화 · 서비스 전환과 신규 구축"
- `website/astro.config.mjs`의 Open Graph·Twitter 이미지 URL을 새 파일로 바꾸고, `og:image:alt`에 소개 문구를 반영했다. 새 URL은 플랫폼의 옛 이미지 캐시와 구분된다. 기존 코발트·아이보리 이미지는 보존했다.
- 본문·읽기 저장 구조·독자 체인지 로그는 바꾸지 않았다(2026-10-15 이미지 교체와 같은 범위).

## 검증

- 생성 이미지가 사용자가 승인한 시안과 바이트 단위로 같다. 줄인 제목 블록 오른쪽(x 935-1010, y 250-436)에 남은 글자 조각이 없음을 픽셀로 확인했다.
- 단위 테스트 37개, `scripts/check_project.py`(20장·15패턴·156출처), 56페이지 빌드와 출력 검사(로컬 링크·앵커)가 통과했다.
- 빌드된 HTML 56개 중 공유 메타데이터가 있는 55개가 새 이미지 URL을 쓰고, 옛 코발트 URL을 참조하는 페이지는 없다. 나머지 1개는 `/releases/` 리다이렉트다. 빌드 결과의 PNG가 원본과 같다.

## 한계

- LinkedIn이 작은 썸네일 레이아웃(약 260px 너비)으로 표시하면 소개 글자 높이가 약 6px이 되어 읽기 어렵다. 큰 카드 레이아웃에서는 읽을 수 있다.
- LinkedIn은 미리보기를 캐시한다. 배포 후에도 이미 게시한 글의 미리보기는 바뀌지 않으며, 새 게시물은 Post Inspector로 갱신해야 새 이미지가 보일 수 있다. 실제 LinkedIn 게시물·캐시는 변경하지 않았다.
