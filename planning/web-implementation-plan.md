# 웹 독서판 구현 계획

사용자가 2026-10-13에 웹 공개 제안의 방향과 Astro Starlight·질문 추천·localStorage 구현을 승인했다. 현재 작업 공간의 조사 변경을 보존하고 website 디렉터리에 구현한다. 구현을 먼저 완성해 검토할 수 있게 하며 외부 도메인과 서비스 배포는 별도다.

## 구조와 순서

1. 출판 변환: website/scripts에서 서문·20장·15패턴과 본문 인용 출처만 생성. 내부 링크를 공개 경로로 변환하고 알 수 없는 링크는 실패 처리. 원고 원본은 변경하지 않는다.
2. 독서 화면: Starlight 기본 탐색·검색을 유지하고 홈·목차·패턴·참고문헌·소개 페이지를 구성한다. 본문에서 핵심 판단·관련 패턴·읽기 설정·진도를 제공한다.
3. 추천: 목적별 경로, 역할별 강조, 깊이별 진입 위치를 분리한 순수 함수. 3문항의 되돌리기·건너뛰기·답변 수정과 결과 이유를 구현한다.
4. 진도: 저장 모듈이 방문·읽음·절 위치·판본·추천 답변을 저장한다. 저장 차단·손상·다중 탭·사용 중 초기화·직접 앵커를 처리한다. 읽음은 명시적 행동이다.
5. 검증: 추천 전체 조합·저장 실패·판본 변경·초기화의 단위 테스트, 공개 빌드의 링크·출처·내부 자료 제외 검사, 브라우저에서 추천·진도·검색·모바일을 확인한다.

## 화면 원칙

책 표지를 닮은 큰 제목과 절제된 인디고색 장 번호로 첫 화면을 구성한다. 종이 #faf9f6, 잉크 #202d3d, 인디고 #344c88, 옅은 청회색 #e9edf5, 보조 글자 #536176. 영문 표제는 Georgia, 한글 제목·본문은 시스템 한국어 서체를 사용해 외부 폰트 요청을 만들지 않는다. 목차의 장 번호만 순서 표시로 쓰고 장식용 카드 반복을 피한다. 본문은 왼쪽 정렬, 여유 있는 행간, 모바일 한 열로 읽는다.

## 완료 조건

빌드 결과에서 원고와 인용을 읽을 수 있고, 추천이 실제 존재하는 장을 안내하며, 재방문 시 진도와 위치가 복원된다. 저장 불가 상태에서도 읽을 수 있다. 모바일·키보드 접근, 직접 링크, 이전·다음, 검색을 확인한다. 실제 독자의 이해도와 추천 효과는 구현 테스트와 구분한다. 커밋·푸시는 이번 요청에 포함하지 않는다.
