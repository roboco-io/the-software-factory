# S112 채택 범위

- 확인일: 2026-10-17. 서지는 sources.json의 S112를 기준으로 한다. 웹 도구로 본문 전체를 직접 읽었으며 이미지 도표와 연결된 별도 원문은 검증하지 않았다.
- 원문 절 대응: 7장 → Layer by layer의 1·2, 12장 → 5 및 Where this is going, 17장 → The scarce resource, 19장 → How we make the reviewer better. 장별 S112 문단이 채택한 사실의 유일한 상세 요약이다. 중복된 조사 카드나 수치 목록을 만들지 않았다.
- 확인 수준: 작성 주체의 자체 운영 설명. 내부 설정·로그·시스템 실행·독립 재현을 확인하지 않았다. 공개 제품과 팀 내부 운영의 차이는 12장에 남겼다.
- 독자 판단: 판정 근거·수용 권한·비용·개선 종료 조건을 각 장에 연결한다. 본문의 ‘이 책은’ 및 ‘이 책이 얻는 해석’ 뒤는 저자 해석·제안이며 사례의 검증된 효과로 표시하지 않는다.
- 채택하지 않은 것: 성과 수치, 전체 위험표, 제품 설정·명령, 도표 이미지, 장별로 원문을 재구성한 번역. 수치가 틀렸다는 판단이 아니라 책의 판단에 꼭 필요한 사실만 선택한 것이다.
- 인용 검토: 직접 인용 0. 네 장의 사실 의역을 짧게 제한하고 주장 메모·체인지 로그에서는 원문 사실을 다시 나열하지 않는다. 서지·확인 범위를 포함해 200단어 기본 상한 안의 제한적 사용이며 기사 대체물을 만들지 않는다.
