# Anthropic: 완료 보고와 결과 상태의 구분

- 출처: [S10]
- 자료 성격: 에이전트 평가 설계 지침
- 확인일: 2026-10-11
- 연결 패턴: P06, P07, P08

## 확인한 설명

지침은 수행 기록과 최종 결과를 구분하고 과업에 맞는 판정 수단과 평가 환경을 다룬다. 평가 대상에 모델과 하네스의 조합을 포함한다.

## 저자 해석

완료 선언과 실제 결과의 증거를 구분하고, 실행 주체의 선별을 업무·하네스·환경의 조합 단위로 설계할 수 있다.

## 한계

방법 지침이며 일반 조직의 생산성 효과를 검증한 운영 사례는 아니다. 원문의 예약 설명은 예시이며 실제 예약 사건이나 성과로 제시하지 않는다.
