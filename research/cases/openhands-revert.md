# OpenHands: 검증 경계를 벗어난 소비자 영향과 복구

- 출처: [S13], [S18]
- 확인 범위: 두 PR의 관련 본문, 복구 PR의 병합 기록
- 확인일: 2026-10-11
- 연결 패턴: P06, P07, P11, P15

## 확인한 사실

PR #18048은 Enterprise 전환이 준비되지 않아 기존 경로를 복구한다고 설명하며 2026-10-06 병합되었다.[S13]

PR #17660은 집중 테스트 통과를 보고하되 배포 패키지 검증은 주장하지 않는다.[S18] 이는 작성자의 보고이며 실행 결과를 재현한 것은 아니다.

## 저자 해석

한 저장소의 검사만으로 소비자 시스템의 영향을 충분히 보지 못할 수 있다. 검증 경계와 의존 시스템을 함께 살피는 반례 후보로 사용한다.

## 미확인

#17660의 검색 제공 본문에는 이전 수집본의 Draft 상태가 표시된다. 현재 상태를 이 표시로 단정하지 않는다. Checks·Files changed와 공개 API 열기는 실패했다. 전체 리뷰·CI 로그와 Enterprise 환경은 추가 확인이 필요하다. AI 승인만으로 병합되었다는 과정, 실제 피해 규모나 생산성 영향은 단정하지 않는다.

## 리더의 결정과 적용 경계

변경을 사용하는 시스템의 수용 조건을 검증 범위에 포함할 책임을 정한다. 여러 소비자 환경을 유지하는 비용도 평가한다. 현재 근거는 검증 범위의 질문을 제기하는 데 사용하며, 실패 원인의 실증 자료로 사용하지 않는다. 7장에 반영했다.
