# 로보코: 공개 저장소에서 관찰한 팩토리 구조

- 출처: [S01], [S02]
- 자료 성격: 저자 제안과 공개 저장소 사례 조사
- 확인일: 2026-10-11

## 확인한 분석 방식

조사는 작업 유입, 병렬 흐름, 자동 검증, 위험별 위임, 보고와 개선을 기준으로 저장소를 읽는다. 알려진 사례와 봇 PR 검색에 기초한 표본이다. [S02]

## 책에서의 사용

이 기준을 패턴 후보와 반례를 찾는 출발점으로 삼는다. 개별 사례의 코드는 고정 커밋과 PR 및 확인일에 연결해 재검토한다. 개발과 운영 피드백을 잇는 생산 체계라는 논지는 저자의 제안이다. [S01]

## 한계

저자의 판별 기준을 통용 표준으로 제시하지 않는다. 표본에서 자동화 장치가 보인다는 사실을 보급률·완전 자동화·인과 효과의 증거로 확대하지 않는다. 비공개 운영 경로는 공개 범위만으로 판단하지 않는다.
