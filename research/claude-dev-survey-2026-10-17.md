# claude.dev 조사와 원고 반영 제안

확인일: 2026-10-17. 사용자의 멀티 에이전트 조사 요청에 따라 세 하위 에이전트와 주 에이전트가 관련 글 11편의 원문을 직접 읽었다. 이 문서는 편집 제안이며 본문·패턴·사이트 변경이나 채택 확정이 아니다.

## 조사 범위와 확인 수준

- 홈페이지 최신 목록에서 7편, 검색으로 찾은 하네스·스킬 관련 이전 글 4편을 선택했다. 사이트 전수 조사·전체 페이지 로딩·영상 시청을 수행한 것은 아니다. 이미 반영한 코드 리뷰 글 S112는 제외했다.
- 조사 분담: 자동화/클라우드 2편, 평가/비용 3편, 확장/협업 사례 2편을 세 하위 에이전트가 확인했다. 주 에이전트는 이전 글 4편을 읽고 보고를 통합했다. 평가 잡음·권한 확장 한계·협업 사례의 승인 조건 등 주요 지점은 원문을 다시 대조했다.
- 원문의 상세 사실과 한계는 아래 담당 메모 한 곳에만 요약했다. 출처 S113~S123과 후보 주장 메모를 연결했다. 기존 112출처 객체는 보존한다. 조사 과정의 여러 에이전트 사용은 독립 재현이나 원문 주장의 참을 보증하지 않는다.
- 업체의 내부 경험·설계·튜토리얼을 실제 팩토리의 보편적 효과로 쓰지 않는다. 2026년 4~6월의 선행 경험과 9~10월의 후속 설명은 각각의 발표 시점을 유지한다. 로보코의 정의를 원문 작성자가 제안했다고 소급하지 않는다.

## 우선 반영 제안

아래는 원문 사실의 반복 요약이 아니라 기존 원고에 추가할 저자 해석·설계 제안이다.

| 우선순위 | 연결 출처 | 장·절 후보 | 독자가 새로 판단할 것 |
|---|---|---|---|
| 1 | S113 | 8장 오류/미확인 구분, 9장 실행 지속, 14장 보고 | 자동화가 조용할 때 관측 성공과 누락을 구별한다. 상태 갱신을 실제 결과 확인에 연결한다. |
| 2 | S115 | 11장 평가 자체의 오류, 19장 기준 고정/갱신 | 개선 차이를 구별할 수 있는 평가인가를 먼저 판단한다. 결과를 보고 후보를 고르는 데 쓴 자료를 완전히 독립된 최종 검증이라고 부르지 않는다. |
| 3 | S120 | 3장 정책/계획, 6장 분해, 9·12장 집행 | 실행 구조를 동적으로 만들어도 원칙·권한·자원·종료 조건은 유지한다. 분리한 역할 사이의 요약도 신뢰 경계를 자동 통과하지 않게 한다. |
| 4 | S122 | 10장 지식 유지, 13장 공통 기반, 19장 개선 | 개인의 작업 요령을 소유자·판본·평가·폐기 조건을 가진 공유 자산으로 관리한다. |
| 5 | S119 | 13장 투자, 14장 필요한 협의, 15장 운영 방식 | 조직도 변경에 앞서 작업 책임·좁은 범위·조정 경로를 설계한다. 확대와 종료를 유지비·사용자 영향으로 판단한다. |
| 6 | S121 | 10장 맥락 공급, 11장 조합 평가, 19장 개선 | 모델 교체 때 새 능력뿐 아니라 기존 보조 장치가 여전히 유효한지도 재평가한다. |

권장 순서는 1·2를 먼저 반영하고, 3·4를 하네스/조직 자산 설명에, 5·6을 기존 논증의 짧은 사례로 보완하는 것이다. 새 장·새 패턴은 필요하지 않다. 의도 정의·개선 파이프라인은 자료 발견과 현재 상태 확인에, 전자동 개발은 위임·실행 구조에, 하네스 개선은 평가와 실패 환류에 연결한다.

## 보조 후보와 보류

| 출처 | 판단 |
|---|---|
| S114 | 5·9·12장의 실행 격리와 통합 책임을 보조할 수 있으나 기존 데모와 중복을 먼저 줄인다. |
| S116 | 11·17·19장의 자원 증액 판단 후보. 실패 원인을 분류한 뒤 다루고 특정 모델/설정의 영구 처방을 피한다. |
| S117·S123 | 17장의 총비용에 짧은 비교 관점을 더한다. 최신 가격표·제품 설정을 본문에 넣지 않는다. |
| S118 | 9장 확장 기능의 경계에 짧은 반례로 한정한다. 튜토리얼을 재현하지 않는다. |

성능 배수·PR량·절감률, 제품 설치 명령, 모델 추천표, 원문의 분류표·도표 전체는 반영하지 않는 편이 적절하다. 특정 사례에 남은 사람 승인을 팩토리의 필수 조건으로 일반화하지 않고, 캐시나 편의 때문에 보안 경계를 유지하지 않는 선택을 권하지 않는다.

## 후속 반영 상태 · 2026-10-17

저자의 후속 지시에 따라 우선순위 1~6을 기존 장에 반영했다. 위의 ‘본문 미반영’은 조사 완료 당시의 상태다. 보조 후보 5개는 이번에 채택하지 않았다. 중복 통합·장별 연결·근거 사용 범위는 [반영 메모](claude-dev-adoption-note.md)와 [수정 검증](../planning/reviews/2026-10-17-claude-dev-adoption.md)에 기록한다. 커밋·게시 전 로컬 원고다.
