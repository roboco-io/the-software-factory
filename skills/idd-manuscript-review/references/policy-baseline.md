# 휴대용 리뷰 기준

2026-10-13 IDD 원고 리뷰 정책 제안에서 추출했다. 프로젝트의 최신 정책을 우선한다. 이 기준은 정책 적용 방법이며 원고 승인 기록이 아니다.

| 우선순위 | 판정 | 처리 |
|---|---|---|
| P0 | 창작된 사례·인용, 중대한 사실 오류, 근거 범위를 넘긴 성과·권리 주장 | 확인·삭제·축소 전 편집 확정 보류 |
| P1 | 중심 논증 모순·누락, 패턴 의미 변형, 결정·작동 원리·비용·한계 불명확 | 내용 수정 후 재검증 |
| P2 | 이해를 막는 용어·반복·문단 연결·예시·표현 | 수정 또는 보류 이유 기록 |
| P3 | 선택 가능한 문체·구성·예시 제안 | 저자 선택 |

취향을 P0/P1로 올리거나 총점으로 필수 결함을 상쇄하지 않는다. 조건·구조·비용·관찰을 밝힌 미검증 제안은 현장 실험 부재만으로 탈락시키지 않는다. 효과가 입증되었다는 단정은 별도로 근거를 확인한다.

주요 제한: IDD 최초 명명·조직 확장 최초성 단정 금지. 모델 의존 감소와 최소 능력·비용 차이 제거를 혼동하지 않는다. 완전 자동화에는 대상·성공·정지·복구·인간 책임이 필요하다. 조직 개편은 병목에 따른 조건부 판단이다. 코드·토큰·PR 수는 활동 지표이며 사용자 결과와 다르다. 심리적 오너십·인지적 참여·실제 책임 행동을 구분한다.

『More Effective Agile』 공개 목차 대응은 본문 논증 검토가 아니다. 적법하게 읽은 판본·장절 범위에서만 구체적 동의·반박을 한다. 기본 출처 한도는 출처당 직접 인용 25단어, 요약·의역 200단어이며 모든 사용 파일을 합산한다. 별도 허락·더 엄격한 한도를 확인한다. 한국어 공백 집계만으로 준수를 확정하지 않는다.

리뷰 상태: `열림` → `수정됨·검증 대기` → `검증 완료`. 저자 결정이 필요하면 `저자 판단 대기`, 미채택이면 `채택하지 않음·이유 기록`. 필수 문제의 미채택은 해결로 취급하지 않는다. 편집 확정은 지정 버전의 P0/P1 해소, P2 처리 기록, 적절한 한계 표현과 실제 저자 승인이 필요하다.
