# GA4 운영

## 활성화

1. 기존 홈페이지와 분리한 책 전용 GA4 속성의 웹 스트림의 측정 ID(G-...)를 확인한다. GitHub 저장소 Actions 변수 `PUBLIC_GA_MEASUREMENT_ID`에 입력한다. 비밀키가 아닌 공개 태그 ID이며 API secret을 넣지 않는다.
2. 사용자 선택에 따라 **향상된 측정을 사용한다.** 조회·스크롤·외부 클릭·해당 파일 다운로드 등 일반 행동은 Google 태그가 수집하고, 추천·읽음 기능 세 이벤트만 직접 전송한다. 페이지 조회나 외부 클릭을 별도로 전송하지 않는다. 검색·폼·동영상 옵션은 실제 기능과 수집 범위를 확인해 선택한다. 검색어·링크 URL·폼 식별자 등이 자동 이벤트에 추가될 수 있다. Google signals·광고 연결·광고 개인화는 사용하지 않는다. 관리 화면의 보관 기간도 운영자가 확인한다.
3. Pages를 빌드·배포한다. ID가 없거나 형식이 다르거나 공개 사이트와 호스트가 다르면 태그를 로드하지 않는다. 로컬 검증은 별도 테스트 속성·SITE_URL과 네트워크 모의 응답을 사용한다.
4. 동의 전/거절 상태에서 Google 요청이 없고, 동의 뒤 실시간 보고서의 페이지 조회·행동 이벤트가 도착하는지 확인한다. 개발 테스트는 실시간 보고서 수신 검증을 대신하지 않는다.

## 전송 목록

| 이벤트 | 직접 전송하는 매개변수 |
|---|---|
| page_view·scroll·click 등 | GA 향상된 측정. 최초 config의 page_location은 쿼리·fragment 제외, referrer는 origin만 지정 |
| guide_complete | chapter_count |
| recommendation_open | chapter_id |
| chapter_mark_read | chapter_id |

맞춤 매개변수는 GA 관리자에서 이벤트 범위 맞춤 측정기준으로 등록해야 보고서에서 편하게 사용할 수 있다. 추천 답변과 전체 localStorage 기록·검색어·원문 URL의 쿼리는 맞춤 이벤트에 넣지 않는다. 향상된 측정의 링크 URL·검색어 등은 별도의 자동 수집 범위이므로 GA 설정과 실제 요청을 함께 점검한다. 이미 동의 전에 수행한 행동은 수집하지 않고 나중에 재전송하지 않는다. URL 쿼리를 제외하므로 UTM별 상세 캠페인 분석은 이번 범위에 포함하지 않는다.

## 동의와 철회

Basic 방식: 별도 키 `software-factory.analytics.v1`에 선택·시각만 저장한다. 180일 만료 시 다시 선택하며, localStorage 저장 실패에 대비해 같은 선택을 책 전용 동의 쿠키에도 보존한다. 둘 다 저장할 수 없으면 현재 문서의 명시적 선택만 적용한다. 과거 동의를 복원할 때 철회 가능한 저장 상태도 확인한다. 철회·다른 탭의 철회·동의 만료는 수집 비활성화, GA 쿠키 삭제와 문서 재로딩으로 로드한 SDK를 종료한다. 책 전용 `sfbook` 쿠키 접두어와 factory.roboco.io 호스트 범위를 사용해 홈페이지의 `_ga` 쿠키는 삭제하지 않는다. 읽기 저장 키와 기능은 별도다. 이미 전송한 데이터와 Google 측 보관 기간은 브라우저 쿠키 삭제와 구분한다.
